Updating Inbound and Sprawl works while they run in the tray.

- An app whose own installer stops it (Sprawl, Inbound) is no longer refused for having no window to close: Hub asks, waits a moment, then runs the installer, which closes the app as it would if you ran it yourself. Hub still never ends a process.
- If the installer cannot close the app, the row says so with the exit code and leaves the old version in place.
- Inbound's server process is watched too.
