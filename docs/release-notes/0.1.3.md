The catalog has six apps: Purge and Barbican join it.

- Purge (`Kaan88/purge`), an uninstaller that also removes what a program leaves behind. Installed for all users like Sprawl, so an install or update shows Windows' consent prompt. Its windowless engine and elevated helper (`purge-engine.exe`, `purge-broker.exe`) are closed by its own setup, which Hub runs as double-clicking it would. Its v0.1.0 release already carries `hub.txt`, so Hub reads its version, notes and update.
- Barbican (`Kaan88/barbican`), mail, calendar, contacts and files for JMAP servers, installed per user. It has no release yet, so until its first one carries `hub.txt` its row says "no release information" and Hub offers no install for it: nothing is guessed.
- Both rows draw their app's own icon, and the demo set shows them.
- `tools/samples` gains Purge's `hub.txt`; a test now parses and round-trips every catalog app's sample and names Barbican as the only app without one, because it has no release to take a sample from.
