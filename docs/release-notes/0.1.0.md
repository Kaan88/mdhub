First release: a tray launcher and updater for mdedit, mdview, Sprawl and Inbound.

- Shows which of the four apps are installed, their versions and what is new; list, large icons and small icons.
- Checks GitHub for updates (never at start; every 6 hours by default), downloads, verifies SHA-256 and installs or updates each app its own way; asks an open app to close, never kills it; one version kept for roll back.
- Lives in the tray with an update-count badge and one notification per new set of updates; optional start with Windows.
- Updates itself from this repository's releases.
- Unsigned: Windows SmartScreen or antivirus may warn.
