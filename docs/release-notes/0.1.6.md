Smooth transitions, a window that opens where you left it, Claude Switch in the catalog, and a polish pass.

- Claude Switch is the seventh app Hub lists, installs and updates.
- Hover, menus, the settings card, the list and grid views, the release notes page, row status and download progress move smoothly instead of jumping. Windows' "Animation effects" setting turns this off, and nothing runs once the window is still.
- The window opens where it was last, at the size it had, maximized if it was. If that place is no longer on any screen, it opens centred.
- The window is a little taller by default (860×660), so the whole list, the details and the status bar fit.
- Buttons act when the mouse is released over them, so pressing and dragging away cancels.
- Small tiles have a "..." menu, so an app can be installed from them; arrow keys keep the selected tile in view.
- Below 900 px a search button opens the filter; a filter with no matches says so and has a Clear button. "Update all" counts every app with an update, not only the ones shown.
- The release notes page keeps the keyboard while it is open: Tab and Enter reach its own buttons.
- The question before Hub closes an app to update it is tinted as a warning; the maximize button shows Restore when the window is maximized; long messages in the status bar are shortened rather than clipped.
- Settings and the tray menu use the same plain wording. Links in release notes no longer look clickable, and the page's button says "View on GitHub".
